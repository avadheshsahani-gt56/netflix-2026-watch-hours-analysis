# Netflix 2026 Watch Hours Analysis | Power BI

## Project Overview

This project is an interactive Netflix Watch Hours Analysis Dashboard developed using Microsoft Power BI.

The dashboard analyzes audience size and watch-time behavior across different devices, genders, regions, age groups, and favorite genres.

The goal of this project is to transform raw audience data into an interactive and visually informative dashboard that can help understand viewing patterns and audience behavior.

## Business Questions

This dashboard helps answer questions such as:

1. What is the total audience?
2. What is the total watch time?
3. Which devices generate higher watch hours?
4. How is watch time distributed across genders?
5. Which regions contribute to watch activity?
6. Which genres have higher watch hours?
7. How does watch time vary across different age groups?
8. How does the dashboard change when filtering by gender?
